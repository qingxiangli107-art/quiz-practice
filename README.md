# 数据智能体应用赛道 - 知识赛题库演练系统

## 简介
本系统是一个纯前端网页应用，仅限于开发者本人自己的学生用于"数据智能体应用赛道"知识赛的在线演练和模拟测试。

## 功能特点

### 演练模式
- 包含全部题库题目（270道）
- 支持按题型筛选：单选题、多选题、判断题、案例分析题
- 作答后立即反馈对错
- 答错显示正确答案和简要解析
- 自动保存答题进度（本地存储）
- 支持重置进度

### 测试模式
- 从题库中随机抽取100道题目
- 模拟真实考试环境，限时120分钟
- 单题展示，支持题号导航
- 支持标记不确定的题目
- 交卷后显示总分、正确率和各题型得分
- 错题分析：显示错题、你的答案、正确答案和解析
- 保存历史成绩记录

## 使用方法

### 方式一：直接打开（推荐）
1. 下载本文件夹中的所有文件
2. 双击 `index.html` 文件，用浏览器打开即可使用

### 方式二：本地服务器
```bash
cd 知识赛网页版
python3 -m http.server 8080
```
然后在浏览器中访问 `http://localhost:8080`

### 方式三：部署到静态托管
将本文件夹中的所有文件上传到任意静态网站托管服务（如 GitHub Pages、Netlify、Vercel 等）即可在线访问。

## 文件说明
- `index.html` - 主页面
- `style.css` - 样式文件
- `app.js` - 应用逻辑
- `questions.js` - 题库数据（265道题目）

## 数据说明
- 题库来源：3套知识赛模拟题
- 题目数量：265道（单选、多选、判断、案例分析）
- 答案和解析已内置
- 答题记录保存在浏览器本地，不会上传到服务器

## 浏览器兼容性
- Chrome / Edge / Firefox / Safari 等现代浏览器
- 支持电脑和手机访问
- 建议使用最新版浏览器以获得最佳体验

## 注意事项
1. 首次打开可能需要几秒钟加载题库数据
2. 答题进度保存在浏览器本地，清除浏览器数据会丢失进度
3. 测试模式的100道题每次随机抽取，题目顺序和组合都会变化
